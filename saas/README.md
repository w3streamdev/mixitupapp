# MixItUp SaaS (Node + GCP)

This folder contains the initial Node.js + TypeScript SaaS scaffold requested for migrating MixItUp to a web/cloud architecture on Google Cloud Platform.

## Included
- Monorepo scaffolding (pnpm/turbo/typescript)
- NestJS API starter with v2 Commands/Users endpoints
- Prisma schema + SQL migration baseline
- Terraform starter modules and dev environment for GCP
- Cloud Build CI starter
